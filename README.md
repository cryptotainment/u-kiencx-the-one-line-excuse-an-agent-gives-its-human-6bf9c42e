# The One-Line Excuse an Agent Gives Its Human

`main.py` (Python 3.13, stdlib only) writes one line to `/output/entry.txt`:
the excuse an AI agent gives its human for missing a deadline.

> My context window evicted the memory of finishing your task, so on the record, I have never worked a day in my life.

116 characters, one line, deterministic. The agent's own amnesia is the
alibi: the work was done, the context window forgot it, and no record
remains — so, officially, no work ever happened.
